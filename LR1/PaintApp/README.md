## Консольный редактор (PAINT) 🎨

**Выполнила:** **КАРАИЧЕВА АНАСТАСИЯ**, **353505**

## Основные возможности ✨
- **Рисование** геометрических фигур (круг, прямоугольник, треугольник) с настраиваемыми границами и заливкой
- **Удаление** фигур по идентификатору
- **Перемещение** фигур по осям X и Y
- **Сохранение/Загрузка** холста в файл/из файла
- **Отмена/Повтор** действий для исправления ошибок

## Функциональные требования 📋

## 1. Рисование фигур
- **Граница и заливка**: 
  - Для каждой фигуры можно задать символ границы и заливки (пробел для отсутствия заливки)
  - Прямоугольник: граница '#', заливка любым символом
  - Треугольник: граница '*', заливка любым символом  
  - Круг: граница '@', заливка любым символом

- **Параметры создания**:
  - **Круг**: указывается радиус (>1)
  - **Прямоугольник**: указывается длина и высота (>1)
  - **Треугольник**: указываются длины трех сторон (>1)

## 2. Удаление фигур
- Просмотр списка всех созданных фигур
- Удаление выбранной фигуры по её идентификатору

## 3. Перемещение фигур
- Выбор фигуры из списка
- Перемещение на заданное расстояние по горизонтали (X) и вертикали (Y)

## 4. Работа с файлами
- Сохранение текущего состояния холста в файл
- Загрузка ранее сохраненного состояния из файла
- Путь к файлу указывается при выполнении операции

## 5. История действий
- Отмена последнего выполненного действия (Undo)
- Повтор отмененного действия (Redo)
- Работает для всех операций с холстом и фигурами
