# Веб-приложение для совместного планирования мероприятий 
Караичева Анастасия, группа 353505 
# Описание
Веб-приложение для совместного планирования мероприятий с поддержкой:
   - Создание и управление мероприятиями
   - Приглашения участников
   - Уведомления о мероприятиях
   - Интеграция с календарем

# Функциональные требования 📋 
### 1. Управление пользователями
- Регистрация: создание аккаунта, указывая имя пользователя, пароль и email.
  - имя пользователя должно содержать минимум 6 символов
  - пароль состоит минимум из 8 символов
- Вход: аутентификация пользователя по имени и паролю.
   - проверка на правильность ввода имени/пароля
### 2. Управление мероприятиями
  - Создание мероприятия: пользователь выбирает время и место,вводит название и приглашает участников.
    - название состоит минимум из 3 символов
    - дата и время проведения мероприятия выбираются в календаре
    - место пишется в текстовом поле
  - Удаление мероприятия.
### 3. Приглашение участников
  - Приглашение будет отправляться либо на email,либо в приложении.
    - статус приглашения: ожидание, принято, отклонено
  - Участник принимает или отклоняет приглашение.
### 4. Уведомления
  - Push-уведомления за день до проведения мероприятия.
### 5. Интеграция с календарем
  - Мероприятия автоматически добавляются в календарь.
